# Ngiro Treasures

**Sacred Wellness from the Slopes of Mount Ngiro**

This is the static website for Ngiro Treasures, a premium herbal and honey brand originating from Mount Ngiro in Samburu County, Kenya.

## Brand Pillars
1. Sacred origin – Mt. Ngiro
2. Indigenous knowledge – Samburu herbal traditions
3. Pure natural products – raw honey and herbs
4. Community empowerment

## Project Structure
- `index.html`: The main homepage built with HTML, Tailwind CSS (via CDN), and FontAwesome.
- Images: Product and background imagery.

## Getting Started
Simply open `index.html` in any modern web browser to view the site. No build process is required.
